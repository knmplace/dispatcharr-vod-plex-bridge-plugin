HTTP Remote Settings
The available keys depend on the remote type. Your current remotes are http remotes, and the official rclone HTTP backend docs list these common settings:
  • url - the actual upstream endpoint, usually a full URL like https://media.example.com/library/
  • no_head=true - skip HTTP HEAD requests; can speed up slow sites, but file size/time detection is weaker
  • no_slash=true - use when the site does not end directory URLs with /
  • no_escape=true - do not escape URL special characters in paths
  • headers=Header,Value,... - send custom HTTP headers on every request
  • description=... - optional label stored in the remote config
If you change the remote type later, the valid settings may be different for that backend.
